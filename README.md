# DryCleaner

 Лабораторная работа № 1

## Задание

Реализовать объектную модель предметной области химчистки и набор unit-тестов с использованием LINQ.

Данные хранятся в памяти в виде коллекций.

## Структура проекта

### DryCleaner.Domain

Основной проект с классами предметной области.

#### Entities

- `Client` — клиент химчистки.
- `Product` — вещь, переданная в химчистку.
- `ProductCategory` — категория вещи и стоимость очистки.
- `Order` — заказ клиента.

#### Enums

- `OrderStatus` — статус заказа.

Возможные статусы:
- `Accepted`
- `InProgress`
- `Ready`
- `Issued`
- `Cancelled`

#### Data

- `DataSeed` — тестовые данные проекта.

Содержит:
- 20 клиентов;
- 10 категорий;
- 30 товаров;
- 50 заказов.

---

## DryCleaner.Tests

Проект с unit-тестами.

### QueriesTestsFixture

Тестовая фикстура.

Подготавливает данные из `DataSeed` для тестов.

### QueriesTests

Класс с LINQ-запросами и проверками результатов.

### Тесты

#### InProgressOrdersInfoOrderedByAcceptedAt

Находит заказы, находящиеся в обработке.

Результат сортируется по дате принятия заказа.

#### Top5ClientsByNumberOfProductsForPeriod

Находит 5 клиентов, которые передали больше всего вещей за указанный период.

Используются группировка и подсчёт заказов.

#### ClientsWithLongestProcessingOrdersOrderedByName

Определяет клиентов по продолжительности обработки заказов.

Результат сортируется по ФИО клиента.

#### Top5MostAndLeastPopularCategoriesForLastYear

Определяет наиболее и наименее популярные категории вещей за последний год.

Используется группировка по категории.

#### ClientWhoSpentTheMostMoney

Определяет клиента, который потратил больше всего денег за всё время.

Сумма рассчитывается по стоимости очистки товаров.

## Основные элементы

**Entity** — класс, описывающий объект предметной области.

**Enum** — набор допустимых значений.

**DataSeed** — набор исходных тестовых данных.

**Fixture** — подготовка данных для тестов.

**LINQ** — запросы и обработка коллекций.

**Unit Test** — проверка правильности работы отдельного участка программы.

## Результат

Реализована модель данных химчистки и набор unit-тестов для обработки данных с помощью LINQ.
